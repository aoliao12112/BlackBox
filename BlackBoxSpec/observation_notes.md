## 2. 逐条观察

### 观察 #1 · 首次启动与协议确认

- **操作路径**：点击 App 图标启动
- **观察到的行为**：
  - 启动后先显示全屏协议页，标题「感谢您使用扫描全能王！」；
  - 正文说明《用户协议》《隐私政策》，并解释个人信息范围；
  - 底部两个按钮：绿色「同意并继续」、灰色「不同意」；
  - 未见系统级相册/相机弹窗，也未见开屏广告。
- **与预期（spec）的差异**：
  - 参考版有合规协议前置页；本项目的 spec 未包含该页，属于**参考版新增的合规要求**，不属于功能切片。
- **证据**：`01_首次启动_隐私协议_00m05s.jpg`

### 观察 #2 · 首页与空状态

- **操作路径**：同意协议后进入首页
- **观察到的行为**：
  - 顶部绿色品牌栏：CS 图标 +「扫描全能王」+ 右侧 VIP 入口；
  - 常驻搜索框，占位文案「试试搜索文档」；
  - 8 宫格：智能扫描 / 导入图片 / 导入文档 / 提取文字 / 扫描证件 / 试卷去手写 / 拍图转 Word / 全部；
  - 「最近文档」区：空状态插画 + 文案「最近还没有查看、扫描和修改过的文档」+ 描边按钮「扫描新文档」；
  - 底部 Tab：首页 / 全部文档 / 工具箱 / 我的，中间是绿色相机 FAB。
- **与预期（spec）的差异**：
  - 参考版首页是「文档库 + 功能宫格」，本项目是「名片列表」，信息架构不同；
  - 参考版空状态给出明确的行动按钮，本项目的空状态为引导扫描，二者行为对等；
  - 参考版有 4 个 Tab 与中央 FAB，本项目无 Tab Bar。
- **证据**：`02_首页_空文档库_00m23s.jpg`

### 观察 #3 · 相机权限被拒绝

- **操作路径**：首页 → 扫描入口 → 进入相机
- **观察到的行为**：
  - 屏幕中央弹出自定义弹窗，文案：
    「扫描全能王需要使用相机拍摄文档，请到「系统设置」-「扫描全能王」-「权限」，打开相机权限」
  - 两个按钮：「拒绝」（灰）「设置」（绿）；
  - 弹窗下方仍可见相机页的底部模式栏与快门。
- **与预期（spec）的差异**：
  - 参考版用**弹窗**做拒绝后引导；本项目用**整页权限引导 + 「去设置」按钮**；
  - 能力对等（都可跳系统设置），呈现方式不同，属可接受差异。
- **证据**：`03_相机权限拒绝_00m35s.jpg`

### 观察 #4 · 相机页布局

- **操作路径**：相机权限恢复后进入拍摄页
- **观察到的行为**：
  - 顶部工具栏：关闭（X）、闪光灯、滤镜、HD、更多（竖排三点）；
  - 取景区画面为纯黑背景（录屏时镜头被遮挡/未对准），**未见可见的取景边框或实时描边**；
  - 中部提示：「支持双指缩放拍摄」+ 手指示意动画；
  - 底部模式标签 5 个：提取文字 / 拍图转 Word / **扫描（选中，绿色下划线）** / 扫描证件 / 试卷去手写；
  - 底部中间：圆形快门；右侧：「导入图片」「导入文档」。
- **与预期（spec）的差异**：
  - 参考版有 5 种拍摄模式与 2 个导入入口；本项目只有拍照 + 相册导入 + 重拍；
  - 参考版未见取景引导框（或录屏未呈现），本项目的边界框在拍摄后的检测页显示；
  - 「双指缩放拍摄」是参考版特有交互，本项目未实现。
- **证据**：`04_相机页_缩放提示_00m41s.jpg`

### 观察 #5 · 拍摄后处理与文档详情

- **操作路径**：按快门 → 自动进入处理
- **观察到的行为**：
  - 拍摄后**不经过确认页**，直接进入文档页并显示「正在处理图片…」占位（约数秒）；
  - 处理完成后显示页面图片，顶部标题为「扫描全能王 2026-10-28 13.20」，右侧有重命名（铅笔）与宫格视图按钮；
  - 底部工具 5 个：编辑 / 转 Word / 继续添加 / 分享 / 更多；
  - 页面上有绿色横幅「一键转为 Word 文档，还原排版格式」。
- **与预期（spec）的差异**：
  - 参考版是「自动处理 + 文档编辑」，截图后无「重拍/确认」选择；本项目在拍摄后有预览/重拍/确认，再进边界检测；
  - 参考版支持多页连续添加，本项目一次一张名片；
  - 参考版强调转 Word，本项目强调结构化字段，产物不同（符合功能切片差异）。
- **证据**：`05_拍摄后处理中_00m53s.jpg`、`06_文档详情_00m56s.jpg`

### 观察 #6 · 未登录时的云同步提示

- **操作路径**：文档详情页停留/操作时触发
- **观察到的行为**：
  - 弹出白底弹窗，标题「需要开启同步权限」；
  - 正文：「开启后，将使用云端服务处理文档。注册或登录后，文档将自动保存至你的云空间。」
  - 按钮：「取消」「立即开启」。
- **与预期（spec）的差异**：
  - 参考版存在云同步与账号体系；本项目为纯本地存储，无账号与云同步（作业明确不要求）；
  - 本项目因此不出现此类弹窗，属**合规裁剪**。
- **证据**：`07_云同步提示_01m05s.jpg`

### 观察 #7 · 保存后回到首页

- **操作路径**：返回首页
- **观察到的行为**：
  - 「最近文档」由空状态变为列表，条目显示：缩略图、标题「扫描全能王 2026-10-28 13.20」、日期与页数、复选框；

  - 底部提示「扫描全能王时刻保护你的文档安全」。
- **与预期（spec）的差异**：
  - 参考版保存后回文档库，条目带行内快捷操作；本项目保存后回名片夹，列表行为姓名/公司/职位 + 缩略图；
  - 二者都满足「新增后列表立即更新」，行为对等。
- **证据**：`08_首页_最近文档_01m17s.jpg`

## 4. 与 spec 的主要差异汇总

| 维度 | 参考版（CamScanner 7.28.0 推定） | 本项目（BlackBox） | 判定 |
|------|-------------------------------|--------------------|------|
| 核心对象 | 文档（可多页） | 名片（单张） | 功能切片差异 |
| 首页 | 宫格入口 + 最近文档 + 4 Tab + FAB | 名片列表 + 搜索/标签/扫描入口 | 可接受 |
| 拍摄后 | 直接处理，无确认 | 预览 + 重拍 + 确认 → 边界检测 | 本项目更贴合作业三 |
| 边界处理 | 合并进「旋转裁剪」工具 | 独立检测页 + 四点手调 + 透视校正 | 可接受 |
| OCR 呈现 | 文本层叠加原图，点选即改 | 独立 Raw Text 页 + 结构化字段页 | 本项目更贴合作业四/五 |
| 字段结构化 | 无 | 8 字段 + 多电话分流 + nil 不臆造 | 本项目更贴合作业五 |
| 数据管理 | 文档库 + 账号云同步 | 名片夹 + 本地持久化 + 标签/搜索/备注 | 合规裁剪 |
| 导出 | 转 Word / PDF / 分享 | vCard + 系统通讯录 | 作业要求为准 |

## 5. 对复刻实现的启示

1. **参考版把「识别结果」和「原文」合成一层**，用户改的是叠加文本；本项目拆成「Raw Text → 结构化字段 → 人工校正」三步，流程更长但更符合作业对可解释性和字段级准确率的要求。
2. **参考版对多电话只做整行文本**，本项目必须分流手机/办公/传真——这是作业明确要求，不能照抄参考版。
3. **参考版权限拒绝用弹窗**，本项目用整页引导；两者都能跳设置，属于呈现差异，不需要改。
4. **参考版无「缺失字段不臆造」的可见约束**，本项目以灰色「未识别」占位并保持 nil，这是作业的核心约束，需保留。
5. 若后续要与参考版对齐细节，优先补：结果页字符数显示、搜索框常驻位置、列表行内快捷操作。

### 7.2 边界检测与校正（补第 3 模块）

| 行为 | 官方说明 | 来源 |
|------|----------|------|
| 自动检测 | 拍摄或选图后，自动找到文档边界并显示在屏幕上 | S1 |
| 手动调整 | 不满意可拖动边界上的 **8 个蓝色圆点**；屏幕角落显示放大图辅助手动裁剪 | S1 |
| 方向 / 重置 | 可旋转图像；可「重置自动检测边界」 | S1 |
| 确认 / 返回 | 满意则确认进入下一步（图像增强）；不满意可返回拍摄或选图页 | S1 |
| 已有文档重裁 | 打开文档 →「编辑」-「旋转裁剪」重新选择切边范围 | S3 |
| 批量裁剪 | 「我的」-「文档扫描」-「多拍设置」可选「总是进行切边」或「智能切边」；长按勾选图片 →「更多」-「批量处理图片」 | S3 |

**与本项目差异**：本项目为 4 个角点 + 透视校正；参考版为 8 个控制点（4 角 + 4 边中点）并带放大镜。本项目未实现滤镜/增强模式，参考版有 5 种增强模式（原图 / 提亮 / 魔法色彩 / 灰度 / 黑白）。

### 7.3 名片详情页（补第 6 模块）

官方手册描述的行为：
- 在名片列表点击名片 → 查看名片图像 + 具体联系信息；
- 名片显示区上方工具条提供 **删除 / 导出 / 编辑**；导出为 vCard；
- 快捷菜单支持 **拨打电话 / 发邮件 / 发短信**；
- 备注支持文字、图片、提醒时间，长按备注可删除；
- 支持分组与多选批量操作（归组、群发邮件、群发短信、共享、导出、删除）。

**与本项目差异**：本项目详情页支持电话/邮箱/网址/地图跳转、编辑、删除、导出（vCard / 系统通讯录）；不提供短信、备注提醒、名片背面图像。

### 7.4 搜索（补第 7 模块）

| 参考行为 | 说明 | 来源 |
|----------|------|------|
| 搜索范围 | 在当前分组内搜索联系人 | S4 |
| 关键字 | 任意关键字：数字、拼音、公司名等 | S4 |
| 结果呈现 | 命中的关键字以**蓝色高光背景**显示 | S4 |
| 文档类搜索 | 支持按标签、标题/备注、以及图片内 OCR 文本搜索，结果即时显示 | S1 / S2 |
| 标签筛选 | 搜索框左侧为标签选择器，点开列出全部标签；「All」查看全部 | S1 |

**与本项目差异**：本项目搜索覆盖姓名/公司/职位/电话/Email，支持标签筛选；**未实现关键词高亮**，也**未实现 OCR 原文搜索**。

### 7.5 标签 / 分组（补第 4 模块）

- CamScanner：侧栏「Tags」进入标签管理页；点击标签名查看该标签下的文档；可对单个或多个文档设置标签。
- CamCard：分组管理，可新增分组、改名、删除；名片可归入分组。

**与本项目差异**：本项目用标签实现分类，支持新增/删除标签、按标签筛选；未实现层级分组与批量打标签。

### 7.6 识别结果编辑（补第 5 模块，并修正前文表述）

CamCard 官方手册描述的识别结果页行为：
- 识别结果在「识别结果编辑区」展示，可修改出错内容；
- **选中某一项时，上方名片图会显示该项在原名片上的位置**，便于对比修改；
- 可删除条目（**「姓名」不可删除**）、可「添加其他项目」；
- 可添加名片背面图像；识别不准时可触发云识别；
- 保存时可选分组、保存到通讯录、删除名片，或点右上角保存。

**重要修正**：先前基于 CamScanner 录屏得出「参考版无字段级编辑」的结论，**只适用于 CamScanner**；CamCard 本身是有字段级识别结果编辑的。本项目「8 字段 + 人工校正」的方向与 CamCard 一致，但**未实现「选中字段 → 原图对应位置高亮」**。

### 7.7 持久化（第 8 模块仍未覆盖）

官方手册未描述本地存储策略与 Kill App 重启后的行为；仅能确认 CamScanner 提供可选云同步（录屏 01:05 的「注册或登录后…云空间」提示可佐证）。本项目为本地 JSON + 文件持久化，已由 T18 验证重启后数据保留。
**结论**：该项**仍无参考版一手证据**，保留为空白，不做推断。

### 7.8 二手资料的可信度边界

1. 手册版本（Android 3.0/5.1、iPhone 3.5、Web 1.0）均早于当前版本，**界面可能已改版**；
2. 手册中的界面图片未下载入库，因此**没有可用于并排像素对比的参考截图**；
3. 因此本节的用途是补齐「行为有无」，不能作为 UI 一致性或布局对比的证据。
