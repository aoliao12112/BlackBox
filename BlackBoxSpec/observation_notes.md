## 10. 姊妹产品技术参考（CamScanner 文档提取）

CamCard（名片全能王）与 CamScanner（扫描全能王）同属上海合合信息（INTSIG），
底层技术栈高度重叠。以下技术细节可作为理解 CamCard 内部行为的参考。

### 10.1 边缘检测与透视校正

| 项 | 详情 |
|----|------|
| 技术机制 | **实时计算机视觉边缘检测** + **透视变换算法** |
| 触发时机 | 拍摄后立即自动运行，无需用户确认 |
| 预期行为 | 动态绿色框线锁定文档/名片边界，忽略复杂背景；倾斜拍摄自动矫正为正视图 |
| 手动调整 | 8 个控制点的放大镜边界框，可触控微调顶点 |
| 滤镜 | 原图 / 自动优化 / Omnifix / 魔幻彩色 / 黑白 / 灰度（实时缩略图预览） |

### 10.2 OCR 能力

| 项 | 详情 |
|----|------|
| 支持语言 | 中、英、日、韩等 **41 种语言** |
| 核心能力 | **版面分析（Layout Analysis）** — 解析复杂排版、段落层级、标题关系 |
| 技术演进 | 早期纯 CV → 后期 CV + LLM 多模态理解 |
| 端侧 vs 云端 | 基础检测走 Apple Neural Engine 端侧推理；复杂 OCR / LLM 可能走云端 |
| 免费版限制 | OCR 可预览，完整导出需高级账户 |

### 10.3 相机界面交互

- **取景器**：实时边缘识别 + 动态绿色框线
- **顶部工具栏**：闪光灯 / 手电筒补光 / 网格辅助线 / 自动 vs 手动拍摄切换
- **底部模式选择器**：横向滑动（类似 iOS 原生相机）
- **右下角 FAB**：悬浮高亮相机按钮，唤醒拍摄

### 10.4 主导航架构（对比 CamCard）

CamScanner 主导航界面：
```
顶部：账号头像 + 云端同步状态 + 全文搜索框 + 二维码扫描器
中部：横向可滑动标签栏（全部 / 名片 / 笔记 / 合同 ...）
主区：宫格视图 ↔ 列表视图 切换
右下：悬浮相机按钮 FAB
```

> ⚠️ 对照项：**CamCard 名片夹首页是否采用相同架构？**
> 特别是标签筛选、FAB 按钮、视图切换——这些需要黑盒观察确认。

### 10.5 AI 助理交互模式

CamScanner 的 AI 助理是**底部抽屉（Bottom Sheet）**，支持手势上滑唤醒，
内部预置快捷 Prompt + 自然语言输入框。
> 对照项：**CamCard 是否有类似的 AI 交互入口？**（可能在字段校正页）

### 10.6 关键架构假设（待黑盒验证）

基于姊妹产品推断 CamCard 可能采用的技术栈：

| 模块 | 推断方案 | 待验证 |
|------|----------|--------|
| 边缘检测 | CV 边缘检测 + 透视变换 | 动态框线颜色？是否实时？ |
| OCR | VNRecognizeTextRequest（端侧）+ 云端 LLM | 名片识别准确率如何？ |
| 字段抽取 | LLM / 规则引擎 / 混合 | 字段级准确率？nil 处理？ |
| 图像增强 | Omnifix / 自动校正滤镜 | 名片场景用什么滤镜？ |
| 同步 | iCloud / 自有云 | 免费用户是否有云同步？ |

## 附：CamCard vs CamScanner 核心差异推断

| 维度 | CamScanner（扫描全能王） | CamCard（名片全能王）|
|------|--------------------------|----------------------|
| 核心场景 | 通用文档扫描 + OCR + AI 理解 | 名片识别 + 联系人管理 |
| 输出产物 | PDF / Word / Excel / 图片 | 结构化联系人记录 |
| 识别重点 | 版面还原、表格、公式 | 姓名、公司、电话、Email |
| 数据管理 | 文档库 + 标签 + 文件夹 | 名片夹 + 标签 + 分组 |
| 导出 | PDF / 多格式转换 | vCard / 系统联系人 |

**我们复刻的是右侧一列**——CamCard 的功能切片。
