## 1. 首页（名片夹）观察

### 1.1 首次启动

- [ ] 启动后显示欢迎页？还是直接进入空名片夹？
- [ ] 空名片夹的 UI：列表区域是 placeholder 还是直接显示引导？
- [ ] 空状态文案是什么？
- [ ] 空状态扫描按钮位置（中央？右上角？）

### 1.2 有数据状态

- [ ] 名片列表布局：每行几列？
- [ ] 名片缩略信息：显示哪些字段？（姓名/公司/职位/电话）
- [ ] 是否显示名片缩略图？
- [ ] 列表排序方式（时间倒序？字母？）
- [ ] 是否支持横向滚动 / Tab 切换（全部/标签/收藏）

### 1.3 导航入口

- [ ] 扫描入口在哪里？（右上按钮 / 空状态中间 / Tab Bar）
- [ ] 搜索入口？
- [ ] 设置入口？
- [ ] 是否有 Tab Bar？有几个 Tab？

### 1.4 删除交互

- [ ] 左滑删除？还是长按？
- [ ] 是否有确认弹窗？
- [ ] 是否支持多选批量删除？

## 2. 扫描流程观察

### 2.1 相机页

- [ ] UI 布局：顶部是否有返回/取消？
- [ ] 底部按钮：拍摄 / 相册 / 重拍？
- [ ] 是否有自动检测提示（如 "请将名片置于框内"）？
- [ ] 相机取景框是否有色框引导？

### 2.2 权限弹窗

- [ ] 首次请求相机权限时 App 自己的文案是什么？
- [ ] 拒绝后 App 显示什么？（权限引导页 / 弹窗 / 纯黑）
- [ ] 拒绝后是否有跳转设置按钮？

### 2.3 相册导入

- [ ] 系统相册选择器还是 App 内自定义？
- [ ] 选择后是否直接进入检测还是有预览？

### 2.4 拍摄结果预览

- [ ] 拍摄后是否立即自动进入检测，还是先显示一张原图预览让用户确认？
- [ ] 是否有 "重拍" / "继续" 两个按钮？

---

## 3. 名片边界检测与校正观察

### 3.1 边界检测反馈

- [ ] 检测过程是动画还是进度条？
- [ ] 检测到边界后是否显示描边框？
- [ ] 描边框的颜色 / 动画效果？
- [ ] 是否显示检测到的角度 / 梯形参数？

### 3.2 手动调整

- [ ] 自动检测失败时是否提供手动调整？
- [ ] 手动调整是拖拽四角 / 滑动比例 / 还是整体移动？
- [ ] 调整后的实时预览效果？

### 3.3 确认流程

- [ ] 边界确认后是自动校正并进入 OCR，还是用户需要再点确认？
- [ ] 校正过程中是否有 loading 动画？

## 4. OCR 识别观察

### 4.1 OCR 过程反馈

- [ ] 是否显示 "识别中..."？
- [ ] 是否有进度条？
- [ ] 是否有动画提示（如扫描光线 / 文字浮现）？

### 4.2 OCR 原始文本

- [ ] 是否在 UI 上显示 OCR 原始文本？
- [ ] 原始文本是否可编辑？
- [ ] 还是直接跳到字段解析？

### 4.3 识别失败

- [ ] 完全识别不出文字时 App 怎么处理？
- [ ] 部分识别时怎么提示？

## 5. 字段解析与人工校正观察

### 5.1 字段展示

- [ ] 识别结果按什么字段分类展示？
- [ ] 各字段是否有 icon？
- [ ] 识别置信度是否有视觉反馈（如低置信度标红）？

### 5.2 人工修正

- [ ] 点击字段是否直接进入编辑态？
- [ ] 编辑框是单行还是多行？
- [ ] 是否有撤销按钮？
- [ ] 空字段显示什么（占位符 / "-" / 空行）？

### 5.3 保存流程

- [ ] "保存" 按钮位置在哪里？
- [ ] 保存过程中是否有 loading？
- [ ] 保存成功后跳转回哪里？
- [ ] 是否有 "取消" 按钮？取消是否弹窗确认？
